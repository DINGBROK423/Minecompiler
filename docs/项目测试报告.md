# Minecompiler 项目测试报告

## 1. 测试概述

本测试报告汇总了项目中 `tests/lexer`、`tests/valid`、`tests/invalid` 和 `tests/ir` 四类测试结果，覆盖词法分析、SLR 语法分析、AST 构造、语义分析和 LLVM IR 生成等核心阶段。

测试入口包括：

```bash
make test
make cmake-test
make demo
```

当前自动化测试已全部通过。若本机存在 `clang`，测试脚本会进一步对生成的 `.ll` 文件执行 `clang -c -x ir`，用于验证 LLVM IR 的类型和语法正确性。

测试命令：

```bash
./cmmc --parse tests/invalid/syntax.sy
```

## 6. 总体结论

本次测试覆盖了编译器前端从源程序输入到 LLVM IR 输出的完整链路：

1. 词法阶段能够识别合法 token，支持关键字大小写不敏感、注释过滤、最长匹配和非法字符恢复。
2. 语法阶段能够自动构造 SLR 分析过程，对正确程序输出 `accept`，对错误程序输出带位置的 parser 诊断。
3. AST 构造能够保持程序结构层次，支持声明、函数、表达式、分支和调用节点。
4. 语义阶段能够检查作用域、未定义变量、const 赋值、函数参数、返回值类型和嵌套调用。
5. IR 阶段能够生成全局变量、局部变量、函数调用、条件分支、整型表达式和浮点扩展相关 LLVM IR。

综上，Minecompiler 当前测试用例均已通过，项目实现满足 C-- 编译器前端对词法分析、语法分析、语义分析和中间代码生成的核心要求，并具备较好的错误诊断和回归测试能力。
